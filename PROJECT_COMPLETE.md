## 🔧 How to Use

```bash
# Install dependencies (if needed)
npm install

# Start development server
npm run dev
# → http://localhost:3000

# Run tests
npm run test:unit       # Unit tests
npm run test:e2e        # E2E tests with Playwright
npm run lint            # Linting

# Build for production
npm run build
npm start
```
