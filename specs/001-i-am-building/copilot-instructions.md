# GitHub Copilot Instructions for StaudiyoKehak Website

## Project Overview
StaudiyoKehak is an AI-powered social media content generator and scheduler. This website serves as the landing page and documentation hub.

## Tech Stack
- Next.js 15.5 with App Router
- React 19.1
- shadcn/ui components
- Tailwind CSS v4.1
- TanStack Query v5
- Prisma v6 with MongoDB
- Argon2 for password hashing
- Node.js 22+

## Coding Guidelines
- Follow Test-First Development (TDD)
- Use TypeScript for type safety
- Implement responsive design with mobile-first approach
- Use server actions for form submissions
- Leverage Suspense for loading states
- Follow the constitution principles: AI-Driven, Secure, Scalable

## Component Structure
- Use shadcn/ui for consistent UI components
- Annotate components with user impact, business purpose, technical role
- Implement hover effects and transitions as per design
- Ensure accessibility with proper ARIA labels

## Design Replication
- Color scheme: Purple-blue gradients, green-teal, etc.
- Typography: Bold headings, clean body text
- Layout: Hero, features grid, CTA, footer
- Icons: Lucide React icons

## Interactive Features
- Placeholder workflows for AI content generation
- Calendar components for scheduling
- Authentication forms (placeholders)
- Responsive navigation

## Testing
- Vitest for unit tests
- React Testing Library for components
- Playwright for E2E tests
- Test all user scenarios from spec
